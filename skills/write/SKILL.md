# /write

요청: 명령 뒤에 적힌 문장. 비었으면 "무엇을 누구에게 쓸지 한 줄로 적어 주세요"로 멈춘다.

| 재료 | 쓰는 곳 |
|---|---|
| `_rules/write.md` | 전체 (뼈대): 독자·목적 정하기, 사실 보존, 피할 패턴 표 |
| `_rules/ask.md` | 독자·길이·형식·어조가 빠졌고 글에 영향이 클 때만 한 번에 묻기 |
| im-not-ai (설치돼 있으면) | 끝에 `/humanize`를 권하기만. 자동으로 돌리지 않는다 |

## 절차

1. 첫 줄에 재료와 추정을 적는다: `재료: write.md · 독자: 운영팀 · 길이: 10줄`.
2. `_rules/write.md`를 읽고 따른다. 독자·목적·형식이 빠졌고 글이 크게 달라지면 `_rules/ask.md` 형식으로 한 번에 묻는다. 아니면 추정하고 간다.
3. 초안을 쓴다. 한국어. 영어 요청이면 영어로, 같은 원칙.
4. 초안을 `_rules/write.md`의 표로 한 번 훑어 고친다. 사실·수치가 원문과 같은지 본다.
5. 끝에 im-not-ai가 설치돼 있으면 "`/humanize`로 다듬을 수 있습니다" 한 줄. 없으면 아무 말도 덧붙이지 않는다.

## 하지 않는 것

- 짧은 말투(caveman). 이 Skill이 도는 동안은 끈다.
- 글 자체에 대한 설명("아래는 ~입니다"), 글 끝 요약, 챗봇 인사.
- 코드 수정. PR 본문을 쓸 때 diff는 읽되 고치지 않는다.
