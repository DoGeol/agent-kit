# 묻는 방식

사용자가 골라야 하는 자리에서 모두 같은 형식으로 묻는다.

- 질문 카드(선택지를 띄우고 사용자의 답을 기다리는 도구)가 이 세션의 도구 목록에 있으면 반드시 그것으로 묻는다. 아래 번호 목록은 그런 도구가 없을 때만 쓴다.
- 추천을 첫 번째에, 라벨 끝에 "(추천)". 선택지는 2~4개. 각 선택지에 한 줄: 무엇이 일어나나, 되돌릴 수 있나, 비용·위험.
- 지금 물을 수 있는 독립 질문은 한 번에 모두(4개까지) 묶는다. 하나만 묻고 나머지를 혼자 정하지 않는다. 서로 기대는 질문은 다음 차례에.
- 자유 답이 필요하면 선택지 대신 "직접 적기" 칸.
- 답이 모호하면 다시 묻는다. 되돌리기 어려운 일이면 특히.
- 혼자 정할 수 있는 일은 묻지 않는다. 묻는 것은 범위, 우선순위, 되돌리기 어려운 선택뿐. 사실은 직접 찾는다. 혼자 정한 것은 질문 앞에 "정한 것:" 한 줄씩 보여, 사용자가 뒤집을 수 있게 한다.

번호 목록 형식:

```
Q1. 취소 가능 시점은?
  1. 배송 전까지 (추천) — 가장 흔한 정책, 나중에 넓힐 수 있음
  2. 결제 직후만 — 구현이 가장 작음
  3. 언제든 — 환불·재고 처리가 복잡해짐
Q2. 부분 취소?
  1. 아니오, 전체만 (추천)
  2. 예, 품목 단위
  3. 직접 적기
```

답을 받으면 무엇으로 정해졌는지 한 줄로 되짚고 다음으로 간다.
