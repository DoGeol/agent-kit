# node 팀 규칙

비어 있다. 팀이 채운다. `STACK.md`와 외부 규칙보다 우선한다. 한 줄씩, 예/아니오로 확인할 수 있게.

## 버전·도구
- (예: Node 22, pnpm, TypeScript 5.x strict, ESM)

## 프레임워크
- (예: NestJS. 모듈은 `src/<도메인>/`, DTO는 class-validator)

## 폴더 구조
- (예: `src/`, 테스트는 대상 옆 `*.test.ts`)

## 이름 짓기
- (예: 파일 kebab-case, 클래스 PascalCase, 함수 camelCase)

## 금지
- (예: `any`, `console.log`, default export, `moment`)

## 검사 명령
- (예: `pnpm lint`, `pnpm typecheck`, `pnpm test`)
