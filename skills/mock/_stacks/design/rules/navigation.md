# 내비게이션

영향: 중간. 틀리면 사용자가 "내가 어디 있지"를 잃는다.

## 규칙
- 전역 내비게이션은 한 종류(좌측 사이드바 또는 상단 바). 둘 다 두지 않는다. 항목은 7개 이내, 넘으면 묶는다.
- 현재 위치가 보인다: 활성 항목 강조 + 페이지 제목. 깊이가 2 이상이면 경로 표시(breadcrumb).
- 뒤로 가기는 브라우저 뒤로와 같게 동작한다. 모달·드로어를 열어도 URL이 바뀌면 뒤로로 닫힌다.
- 상세 화면에는 목록으로 돌아가는 길이 있고, 돌아가면 스크롤·필터가 유지된다.
- 외부 링크는 새 탭 + 표시. 내부 링크는 같은 탭.
- 탭은 같은 대상의 다른 면을 볼 때만. 다른 대상이면 페이지. 탭 상태는 URL에.
- 좁은 화면: 사이드바는 햄버거 메뉴로, 핵심 3~5개는 하단 바로. 메뉴를 열면 포커스를 가두고 Esc로 닫힌다.

## 틀린 예
- 사이드바와 상단 바에 같은 메뉴가 둘 다.
- 모달을 열었는데 뒤로 가기가 전 페이지로 이동.
- 상세에서 돌아오면 목록이 1페이지로 초기화.

## 맞는 예
- 좌측 사이드바 6개, 활성 강조, 제목 + breadcrumb, 상세 → 목록 복귀 시 필터·스크롤 유지.

## 이유
내비게이션은 지도다. 지도가 둘이거나 현재 위치가 없으면 길을 잃는다.
