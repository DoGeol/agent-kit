# 대화상자·드로어·확인

영향: 중간. 남용하면 흐름이 끊기고, 빠지면 실수를 못 막는다.

## 규칙
- **모달**은 지금 결정이 필요할 때만(확인, 짧은 입력). 긴 폼·상세는 페이지나 드로어.
- **드로어**는 목록을 보면서 상세·편집할 때. 좁은 화면에서는 전체 화면으로.
- 확인 대화상자는 **되돌릴 수 없는 행동**(삭제, 결제, 발송)에만. 되돌릴 수 있으면 바로 실행 + 되돌리기(토스트).
- 확인 문구는 무엇이 일어나는지 구체적으로("주문 3건을 삭제합니다. 되돌릴 수 없습니다"). 버튼은 동사("삭제")로, "확인/취소" 금지. 위험한 행동은 빨간 버튼 + 오른쪽.
- 파괴적 행동이 크면(계정 삭제) 이름 입력 같은 한 단계를 더 둔다.
- 열리면 포커스를 안으로, 닫히면 열었던 요소로. Esc·바깥 클릭으로 닫힘(입력 중이면 바깥 클릭은 막는다). 제목은 `h2`, `role="dialog"`, `aria-labelledby`.
- 모달 안에서 모달을 열지 않는다. 필요하면 단계로.
- 크기는 내용에 맞게, 최대 높이 넘으면 안쪽 스크롤. 헤더·푸터(버튼)는 고정.

## 틀린 예
- 모든 저장에 "저장하시겠습니까?".
- "확인 / 취소"만 있는 삭제 대화상자.
- 모달 위에 모달.

## 맞는 예
- 삭제 클릭 → "주문 #1203을 삭제합니다. 되돌릴 수 없습니다." [취소] [삭제(빨강)]. 보관함 이동은 바로 실행 + "되돌리기" 토스트 5초.

## 이유
확인은 마찰이다. 되돌릴 수 있는 곳에서는 마찰을 빼고, 되돌릴 수 없는 곳에서만 마찰을 둔다.
